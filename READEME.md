# Programming for AI -- Assignment 3

This repository contains my work for Programming for AI Assignment 3. It
includes the Jupyter notebook, the provided datasets, and the output
files generated during the assignment.

## How to run

1.  Keep the provided data files inside the `data` folder.
2.  Open `Assignment3_Programming_for_AI.ipynb` in Jupyter Notebook or
    JupyterLab.
3.  Run the notebook cells from top to bottom.

Make sure NumPy, Pandas, and Matplotlib are installed before running the
notebook.

## What I found difficult

The sensor data was one of the harder parts, especially handling missing
readings, applying calibration offsets, and using the results to create
the plots and animation. Getting all the figures to display correctly
also took some testing.
